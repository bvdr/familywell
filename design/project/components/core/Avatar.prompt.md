**Avatar** — circular family-member avatar. Initials render in Playfair. Use the pastel tints (`sage`, `blue`, `clay`, `lilac`) to distinguish family members, or `accent`/`subtle` for the signed-in user.

```jsx
<Avatar initial="S" tint="sage" size={52} />
<Avatar initial="MR" tint="accent" size={32} />
<Avatar src="/photo.jpg" size={44} />
```
