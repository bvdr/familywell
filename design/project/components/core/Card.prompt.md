**Card** — the white surface panel. Everything sits on the cream ground in a Card. Use `radius="lg"` for large dashboard panels/stat cards, default `md` for rows. Pass `accentBar="var(--warning)"` for the colored left-bar schedule/event row treatment.

```jsx
<Card radius="lg" padding={24}>…</Card>
<Card accentBar="var(--accent)">School drop-off · 9:00</Card>
```
